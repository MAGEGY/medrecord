# 🔗 How to Connect Your APK to Expo Dev Server

## Quick Answer

**The QR code is generated automatically by Expo CLI** - it's NOT in your app code. Here's how it works:

## Step-by-Step Process

### 1. Start Metro Bundler (Generates QR Code)
```bash
npm start
```

**What happens:**
- Expo CLI starts Metro bundler on port `8081`
- **Automatically displays a QR code** in your terminal
- QR code contains: `exp://192.168.8.177:8081` (your IP + port)

### 2. Build Your APK
```bash
cd android
.\gradlew assembleDebug
```

APK location: `android\app\build\outputs\apk\debug\app-debug.apk`

### 3. Install APK on Device
```bash
adb install android\app\build\outputs\apk\debug\app-debug.apk
```

### 4. Connect to Metro (In the App)

**Option A: Use Dev Menu**
1. Open the app on your device
2. **Shake device** (or press `Ctrl+M` on emulator)
3. Select **"Configure Bundler"**
4. Enter: `http://192.168.8.177:8081`
   - (Use your actual IP from `ipconfig`)

**Option B: Automatic (if using `expo run:android`)**
```bash
npm run test:android
```
This automatically builds, installs, and connects!

## Where the Code Is

### QR Code Generation
- **Location**: Expo CLI (not in your code)
- **Command**: `npx expo start`
- **File**: N/A (handled by Expo CLI)

### Metro Connection
- **Location**: React Native framework (built-in)
- **File**: `android/app/src/main/java/com/medrecord/app/MainActivity.kt`
- **How**: React Native automatically connects in debug builds

### Dev Menu
- **Location**: React Native (built-in)
- **Trigger**: Shake device or `Ctrl+M`
- **Code**: Handled by React Native, not your app code

## Your Current Setup

- **Your IP**: `192.168.8.177` (from ipconfig)
- **Metro Port**: `8081` (default)
- **Connection URL**: `http://192.168.8.177:8081`

## Quick Test Command

```bash
# Terminal 1: Start Metro
npm start

# Terminal 2: Build and run (auto-connects)
npm run test:android
```

## Important Notes

1. **QR Code is for Expo Go** - Since you have native modules, you need a dev build, not Expo Go
2. **Use Dev Menu** - For bare React Native apps, use the Dev Menu to configure bundler
3. **Same Network** - Device and computer must be on same WiFi
4. **Firewall** - Port 8081 must be open

## Troubleshooting

**Can't see QR code?**
- Make sure you run `npx expo start` (not just Metro)
- QR code appears in terminal automatically

**Can't connect?**
- Check IP address: `ipconfig` (Windows) or `ifconfig` (Mac/Linux)
- Ensure same WiFi network
- Try `http://` instead of `exp://` in Dev Menu

---

**TL;DR**: The QR code is generated by `npx expo start` command. For bare React Native apps, use Dev Menu to manually enter the connection URL.
